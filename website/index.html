The problem

You're paying for more internet
than any download uses.

Your laptop is on Wi-Fi. Your phone has a data plan. There may be an Ethernet port, too. A normal download uses exactly one of them and leaves the rest idle — so the slowest link sets your pace, and one hiccup stalls the whole thing.

One link, one ceiling

Browsers and most download managers open every connection on the same network. Faster Wi-Fi is the only way to go faster.

Slow servers, slow you

Plenty of servers throttle each connection. One socket on one network means you never reach what your line can actually do.

Fragile by default

A dropped connection, a sleeping laptop, a Wi-Fi switch — and the download starts over. Big files deserve better.

How it solves it

Cut the file up. Send every piece
down a different road.

  1. 01

    Find every way out

    IDMX lists your network adapters and works out which are Wi-Fi, Ethernet, a tethered phone or cellular, and which are actually online.

  2. 02

    Bind, don't hope

    Each connection is tied to one specific network at the operating-system level, so traffic really leaves through that road — not whichever one your computer prefers.

  3. 03

    Split into blocks

    The file is divided into small blocks. Free connections grab the next one; a fast network naturally takes more, a slow one fewer. The last stretch is raced so a laggard can't hold you up.

  4. 04

    Reassemble & verify

    Blocks land in the right place on disk, the file is checked against its checksum when one is published, and a download that was interrupted simply resumes.

Questions
Straight answers.

      

        
Will it make my internet faster?
If you have more than one separate connection — say home Wi-Fi plus a phone on cellular — yes: the file comes down all of them at once. If your two connections share one router and one line, there's nothing extra to add, and IDMX says so instead of pretending.

        
How do I add my phone's data?
iPhone: plug it in, then on the phone switch on Settings → Personal Hotspot → Allow Others to Join. Android: switch on USB tethering in the phone's hotspot settings — on a Mac you also need the free TetherKit helper (a direct download for Macs with Apple silicon), because macOS can't share an Android phone's data by itself. IDMX has a step-by-step guide with live status on its Networks page.

        
Does it work with any website?
The server needs to support range requests (almost all do). If it doesn't, IDMX falls back to a single connection and tells you why.

        
Does streaming video (HLS/DASH) use every network?
Not yet. Videos that are plain files do. Streamed ones are fetched segment-by-segment by yt-dlp, several segments at a time, on one network.

        
Can a single-file torrent use two networks?
No — that would need a custom BitTorrent client. Multi-file torrents are divided by file across your networks; a single big file uses one.

        
Will it eat my mobile data?
Only if you let it. Each network has its own rules: mark it metered, set a daily or monthly cap, a speed limit, or exclude it per download.

        
Is anything sent to a server?
No account, no analytics, no cloud. The only network traffic is your downloads, plus an optional check for a newer version.

        
What about Linux?
The engine and the command-line tool are built for it, but the desktop app has only been verified on macOS so far. Windows and Linux builds are type-checked and being tested.
